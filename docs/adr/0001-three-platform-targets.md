# Windows, macOS and Linux are all full targets

Status: accepted

DOA2U is feature complete only when its offline modes, media paths and save
flows pass on Windows, macOS and Linux. The sister ports now share one runtime,
which carries doaxbv-re's macOS and Linux hosts, and DOA3 made the same choice
(doa3-re ADR 0002). Windows first would have been cheaper while bring-up still
stops on unbound draws outside the first fight; every acceptance run is now
repeated on all three platforms.
